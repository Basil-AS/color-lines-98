# Retro 98 Theme Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a Yandex-inspired `retro98` theme to web and Android with visible grid, warm beige board, purple chrome, localized labels, parity tests, and a release.

**Architecture:** Extend the existing theme registries and semantic palette blocks. Keep the persisted identifier shared across platforms while preserving the existing contrast-symbol rendering and storage normalization.

**Tech Stack:** React/TypeScript/CSS, Kotlin/Jetpack Compose, Vitest, Gradle/JUnit, GitHub Actions.

## Global Constraints

- Keep existing themes unchanged.
- Use `retro98` on both platforms.
- Preserve shape/symbol cues for color accessibility.
- Run contrast measurements before release.
