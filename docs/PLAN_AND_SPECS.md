**Status**: Approved Specification & Master Plan  
**Target Platform**: Android (Modern Native Stack) + Web (GitHub Pages Standalone)  
**Target Android Version**: Android 8.0+ (API 26+) to Android 15/16 (API 35+)

## 1. Исследование источников и референсов (Research Findings)

### 1.1. Анализ изученных проектов и репозиториев
1. **ColorLinesUnity (Newbilius)**:
   - Полноценная имплементация классической логики на C#.
   - **Алгоритм поиска пути**: Волновой алгоритм Ли (BFS по 4 направлениям). Проверка доступности пути от стартовой клетки к целевой.
   - **Формула очков (Color Lines 1992 / Gamos)**:
     $$Score(L) = 2L^2 - 20L + 60 \quad (для\ L \ge 5)$$
     - 5 шаров: $2(25) - 100 + 60 = 10$ очков
     - 6 шаров: $2(36) - 120 + 60 = 12$ очков
     - 7 шаров: $2(49) - 140 + 60 = 18$ очков
     - 8 шаров: 28 очков, 9 шаров: 42 очка (совпадает со шкалой Lines 98: 10, 12, 18, 28, 42 — поддерживаются обе схемы).
   - **Предикторы (Next Balls)**: 3 шарика генерируются заранее и отображаются в верхней панели. При сгорании линии новые шары не выставляются, и ход переходит игроку.
   - **Анимация пути**: возможность включения отображения шагов («следов») перекатывания шара от ячейки к ячейке.

2. **GNOME five-or-more (Vala / GTK)**:
   - Отличная модульная архитектура: разделение `PieceGenerator`, `Board`, `ThemeRenderer`, `View`, `GameEngine`.
   - Поддержка сменных тем (SVG/PNG спрайты, векторный рендеринг).
   - Гибкие размеры полей (хотя канон — 9×9 с 7 цветами).

3. **Веб-версии (lines-98.ru, bubbleshooter.net, lines98.com, yandex.ru/games)**:
   - Подсветка достижимых клеток при тапе на шарик (UX-улучшение для мобильных экранов).
   - Мгновенная отмена хода (Undo) — важная функция для сенсорных экранов во избежание случайных нажатий.
   - Автосохранение партии в `localStorage` (в мобильной версии — в DataStore).
   - Плавная физическая анимация уничтожения шаров (пульсация, вспышка, частицы).

4. **Извлеченные ресурсы из референсных APK**:
   - В APK `org.game.line98basic-7` обнаружены аутентичные звуковые эффекты:
     - `selectBall.mp3` (выбор шарика / подпрыгивание)
     - `jump.mp3` (перемещение)
     - `eatScore_1.mp3` ... `eatScore_5.mp3` (начисление очков и сгорание линий)
     - `Lose.mp3`, `Win.mp3`, `bom1.mp3`, `ButtonClick.mp3`
   - Извлечены оригинальные спрайты шаров 7 цветов высокого качества.

## 2. Архитектура и стек технологий (Modern 2026 Stack)

### 2.1. Android Native App (`android/`)
- **Язык**: Kotlin 2.1+ (K2 compiler).
- **UI Framework**: **Jetpack Compose + Material 3** (Adaptive layouts, Dynamic Color, Edge-to-Edge).
- **Графика и рендеринг игрового поля**:
  - Кастомный Compose `Canvas` с аппаратно-ускоренным рендерингом 60/120 Hz.
  - Пружинная анимация `androidx.compose.animation.core` (`spring`, `animateFloatAsState`).
  - Система частиц (Particle System) на Compose Canvas для взрывов/сгораний линий.
- **Архитектура**: Clean Architecture + MVI (Model-View-Intent / Unidirectional Data Flow):
  - `core-engine`: Чистый Kotlin (POKO, без зависимостей от Android SDK) — логика доски 9×9, поиск пути BFS, детектор линий, подсчет очков, генератор шаров, история ходов (Undo/Redo).
  - `domain`: UseCases (`MoveBallUseCase`, `SpawnBallsUseCase`, `UndoMoveUseCase`, `SaveGameUseCase`).
  - `data`: Хранилище сессий, настроек и таблицы рекордов через **Jetpack DataStore** + **Room SQLite**.
  - `presentation`: Compose Screens, ViewModels (`StateFlow`), звуковой движок.
- **Аудио & Haptics**:
  - `SoundPool` с предзагрузкой для нулевого latency звуков.
  - Rich Haptic Feedback (`VibratorManager`, `HapticFeedbackConstants`) для тактильного отклика при тапе, перемещении и уничтожении линий.
- **Система тем (Multi-Theme Engine)**:
  - **Modern Theme**: Свежий неоновый/стеклянный стиль, динамические градиенты, Material You акценты.
  - **Lines 98 Theme**: Канонический интерфейс Windows 98, глянцевые шарики с характерными бликами, классические звуки.
  - **Color Lines 1992 Theme**: Ностальгический стиль MS-DOS (Gamos), текстура дерева.

### 2.2. Web Standalone App (`web/` & `src/`)
- **Стек**: Vite + React 19 + TypeScript + HTML5 Canvas.
- **Автономность**: 100% клиентский запуск, поддержка оффлайна (PWA), деплой на **GitHub Pages** одной командой/CI action.
- Общий алгоритмический движок (моделируется 1-в-1 с Kotlin Core Engine).

## 3. Правила разработки, Git, CI/CD и релизы (Strict Standards)

В проекте строго действуют следующие правила:

1. **GitHub репозиторий и ветки**:
   - `main` — защищенная стабильная ветка, только протестированный релизный код.
   - Разработка ведется по веткам фич: `feat/<название>`, `fix/<название>`, `refactor/<название>`.
   - Любое изменение вливается только через **Pull Request (PR)** после прохождения всех CI-проверок.
2. **Conventional Commits**:
   - Формат сообщений: `feat: ...`, `fix: ...`, `test: ...`, `docs: ...`, `ci: ...`, `refactor: ...`.
3. **Версионирование (SemVer)**:
   - Мажорные, минорные и патч-релизы (`v0.1.0`, `v0.2.0`...).
4. **CI/CD Автоматизация (GitHub Actions)**:
   - **Android CI**: запуск `ktlintCheck`, `detekt`, unit-тестов `testDebugUnitTest`, сборка `assembleDebug` и `bundleRelease`.
   - **Web CI / GitHub Pages**: `npm run test`, `npm run build`, автоматическая публикация в GitHub Pages.
   - **Release Workflow**: При создании тега `v*.*.*` сборка релизного APK, генерация changelog и создание GitHub Release с прикрепленными APK и веб-архивом.
5. **Тестирование и проверка перед завершением**:
   - 100% покрытие unit-тестами движка правил (`core-engine`).
   - Проверка алгоритмов поиска пути во всех сценариях (открытый путь, заблокированный путь, лабиринты).
   - Тесты детектора линий: горизонтали, вертикали, обе диагонали, перекрещивающиеся линии (одновременное уничтожение), 5, 6, 7, 8, 9 шаров.
