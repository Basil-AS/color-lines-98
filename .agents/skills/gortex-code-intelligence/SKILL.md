# Gortex Code Intelligence

Use `rg` for direct textual facts and Gortex when relationships, callers, impact, or multiple repositories matter. Check index freshness and register new worktrees before querying. Narrow results, then verify consequential claims against source and tests. Gortex output is supporting context, never proof or permission for mass fixes.
